# 项目文件说明

本仓库用于在花分类数据集（`flower_photos`）上，对比 Vision Transformer 在不同数值精度下的分类表现：

`fp32` / `int8` / `int4` / `int2` / `bit158`（约 1.58 bit）

已删除原仓库中未再使用的旧代码（如 `v.py`、`bitlinear.py`、`BitNet/` 等）。当前保留的文件均为对比实验所需。

## 各文件含义

### `quant_linear.py`

**作用：** 定义可切换精度的线性层 `QuantLinear`，是整个量化对比的核心。

- `fp32`：普通全精度线性层，不做量化。
- `int8` / `int4` / `int2`：对权重做对称均匀量化（按全局 absmax 缩放后取整）。
- `bit158`：BitNet b1.58 风格三值量化，权重落在 `{-scale, 0, +scale}`，有效比特约 `log2(3) ≈ 1.58`。
- 非 `fp32` 时，激活可做 per-token int8 absmax 量化；训练使用 STE（直通估计），便于反向传播。

同时提供：

- `SUPPORTED_PRECISIONS`：支持的精度列表
- `count_effective_bits()`：各精度对应的有效比特数

### `vit_model.py`

**作用：** 实现用于对比实验的轻量 Vision Transformer。

主要模块：

- `PatchEmbed`：把图像切成 patch 并投影到 token
- `Attention` / `Mlp` / `Block`：Transformer 结构；内部线性层使用 `QuantLinear`
- `VisionTransformer`：完整分类模型（含 cls token、位置编码、分类头）
- `build_vit()`：按 `tiny` / `small` 规格快速构建模型

说明：

- Attention / MLP 中的线性层会随 `precision` 切换量化方式。
- 分类头 `head` 固定为 `fp32`，避免分类层精度干扰主干对比。

### `train_compare.py`

**作用：** 一键完成「数据加载 → 逐精度训练 → 验证 → 汇总对比」。

主要流程：

1. 读取 `ImageFolder` 格式数据集（如 `flower_photos`）
2. 按类别分层划分 train / val
3. 对指定精度列表依次训练
4. 保存最优权重、单精度结果 JSON、总表 `summary.csv`

常用参数：

| 参数 | 含义 |
|------|------|
| `--data-dir` | 数据集根目录（需含各类别子文件夹） |
| `--precisions` | `all` 或逗号分隔，如 `fp32,int8,bit158` |
| `--epochs` | 训练轮数 |
| `--max-per-class` | 每类最多使用多少张（`0` 表示全部，适合快速试跑） |
| `--model-size` | `tiny` 或 `small` |
| `--out-dir` | 结果输出目录 |

### `requirements.txt`

**作用：** 列出运行依赖。当前主要需要：

- `torch`
- `torchvision`

### `README.md`

**作用：** 项目简介、论文信息与快速运行命令入口。更细的文件说明见本文档。

### `docs/项目文件说明.md`

**作用：** 本文件。说明仓库结构、每个源码文件职责，以及实验输出目录含义。

### `docs/量化原理说明_QAT.md`

**作用：** 解释权重/激活如何量化、STE 怎么反传，以及为何这是 QAT（量化感知训练）而非 PTQ。

### `runs/`

**作用：** 存放实验产物，不参与模型逻辑。例如：

```text
runs/quick_compare/
├── summary.csv              # 各精度准确率汇总
├── result_fp32.json         # fp32 详细结果与训练曲线
├── result_int8.json
├── ...
├── vit_fp32_best.pth        # 各精度最优权重
└── ...
```

可随时删除后重新跑实验生成。

## 精度对照（简要）

| 名称 | 权重表示 | 约等于比特 |
|------|----------|------------|
| fp32 | 全精度浮点 | 32 |
| int8 | 256 档均匀量化 | 8 |
| int4 | 16 档均匀量化 | 4 |
| int2 | 4 档均匀量化 | 2 |
| bit158 | 三值 `{-1,0,1}`（带缩放） | ≈1.58 |

## 快速运行

```bash
cd /workspace/project/codes/teach_all/VIT/ViT-1.58b-main

# 快速冒烟（每类最多 120 张，3 epoch）
python train_compare.py \
  --data-dir /workspace/datasets/flower_photos \
  --epochs 3 \
  --max-per-class 120 \
  --precisions all \
  --out-dir runs/quick_compare

# 全量更稳妥的对比
python train_compare.py \
  --data-dir /workspace/datasets/flower_photos \
  --epochs 15 \
  --precisions all \
  --out-dir runs/full_compare
```

## 已删除的旧代码（不再使用）

以下内容已从仓库移除，因其依赖缺失（如 `timm` CUDA kernel）、路径写死，或已被本套对比代码替代：

| 已删除项 | 原用途简述 |
|----------|------------|
| `v.py` | 基于 timm 的大型 ViT 定义 |
| `bit_vit.py` / `helpers.py` | 旧 BitLinear 版 Attention/MLP |
| `bitlinear.py` | 依赖未编译 CUDA gemm 的旧量化层 |
| `vitt.py` | CIFAR-10 训练/评测脚本（硬编码路径） |
| `dataset_floder.py` | 自定义 ImageFolder（现用 torchvision） |
| `BitNet/` | 第三方 BitNet 库整包（本实验未调用） |
