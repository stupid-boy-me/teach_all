# docs —— 工具箱与基础操作

> 训练脚本是主角，工具脚本是后勤部。  
> 后勤不行，主角再帅也会在数据清洗阶段倒地。

本目录汇总 PyTorch / 图像处理里**反复出现**的小操作：均值方差、格式转换、可视化、增强、可解释性等。  
代码短、场景碎，但正好适合当「随手抄作业」的抽屉。

---

## 结构

| 路径 | 内容 |
|------|------|
| [`Basic_operation/`](./Basic_operation) | 基础图像/数据脚本：RGB 检查、均值方差、重命名、形态学等 |
| [`utils/`](./utils) | 进阶工具：Grad-CAM、数据增强（含 Mosaic）等 |
| [`utils/Grad_CAM`](./utils/Grad_CAM) | 看模型「盯着哪儿看」 |
| [`utils/Image-Augmentation`](./utils/Image-Augmentation) | 增强相关；含目标检测 Mosaic 等 |

各子目录 README 会继续补例子与适用场景。

---

## 什么时候该来这里翻一翻？

- 数据集里混进了 **RGBA / 灰度**，训练莫名其妙报错  
- 想算一组自己数据的 **mean / std**  
- 想给分类模型加一张 **热力图** 交差/自查  
- 检测数据增强想试试 **Mosaic**，又不想从零写

---

## 使用姿势

多数脚本是「单文件可运行」风格：改路径 → 跑 → 看输出。  
若依赖额外包，优先复用仓库根 [`requirement.txt`](../requirement.txt)。

欢迎把你日常用的小脚本 PR 进来——工具越多，熬夜越少。
