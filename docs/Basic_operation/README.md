# Basic_operation —— 基础图像 / 数据脚本

> 没有英雄光芒的小脚本，却能在关键凌晨救你一次。

| 脚本（示例） | 用途直觉 |
|--------------|----------|
| `judge_picture_RGB.py` | 揪出非 RGB（含 RGBA）图像 |
| `acquire_mean_std.py` | 统计数据集 mean / std |
| `bmp2png.py` | 格式转换 |
| `change_picture_rename_num.py` | 批量重命名 |
| `canny_dilate_GaussianBlur.py` | 经典 OpenCV 操作组合 |
| `class2gray.py` | 类别/灰度相关处理 |
| `find_max_square_from_mask.py` | 从 mask 找最大方阵区域 |
| `acquire_black_sum_from_picture.py` | 统计黑像素等 |
| `PyTorch_GPU版安装.md` | GPU 环境安装笔记 |

用前请先**改路径**，建议先在拷贝数据上试跑。  
更多增强与 Grad-CAM 见 [`../utils`](../utils)。
