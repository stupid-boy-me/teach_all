## 使用原则（短）

1. 先保证标签同步变换（框/mask 一起变）  
2. 增强强度与任务相关：医疗影像别上来就重度扭曲  
3. 验证集一般**不要**花里胡哨——你要测的是泛化，不是滤镜审美
