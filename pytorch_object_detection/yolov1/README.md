# YOLOv1 —— 单阶段检测的「开山鼻祖」

> 一句话：把检测当成回归，整图一次前向，直接吐出框和类别。  
> 今天的 YOLO 家族已经卷出天际，但 V1 仍然是理解「网格思想」的最佳教具。

论文：[You Only Look Once](https://arxiv.org/abs/1506.02640)

---

## 本目录有什么

| 内容 | 说明 |
|------|------|
| 训练 / 模型代码 | YOLOv1 教学实现（以仓库内脚本为准） |
| [`data2voc/`](./data2voc) | 数据转到 VOC 风格的辅助说明与脚本 |
| 根目录 `1voc2yolo.py` 等 | 标注格式转换相关 |

格式转换也可参考同级 [`../1.format_convert`](../1.format_convert)。

---

## 你应该带着什么问题读代码

1. 一张图如何被划成 `S×S` 网格？每个 cell 负责什么？  
2. 边界框是相对 cell 还是相对全图编码的？  
3. 分类与定位的 loss 如何加权？没有物体的格子怎么处理？  

搞懂这三点，再看 YOLOv3/v5 会轻松很多——它们换皮不换魂。
