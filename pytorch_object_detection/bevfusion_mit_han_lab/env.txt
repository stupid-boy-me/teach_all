0. 版本锁定一览（务必遵守）
--------------------------------------------------------------------------------

  组件                推荐版本                 说明
  ------------------  -----------------------  --------------------------------
  Python              3.8.x                    不可用 3.9+
  PyTorch             1.10.1                   官方要求 >=1.9, <=1.10.2
  torchvision         0.11.2
  torchaudio          0.10.1
  cudatoolkit         11.3                     conda 内的 toolkit，不是驱动版本
  GPU 驱动 CUDA       >= 11.3 即可             驱动可更新，例如显示 12.x / 13.x 也行
  Pillow              8.4.0                    更高版本可能出问题
  mmcv-full           1.4.0                    必须用匹配 torch/cuda 的预编译轮子
  mmdet               2.20.0
  nuscenes-devkit     最新 pip 即可            验证过 1.1.11
  openmpi             4.1.x (conda-forge)
  mpi4py              3.1.x (conda-forge)      官方 Docker 写 3.0.3；3.1.x 更易装
  numba               0.58.1                   官方写 0.48.0，与新 numpy 不兼容
  torchpack           pip 最新

  不要：
  - 复用 yolov12 / 其他新版 PyTorch 环境
  - 同时安装 mmcv 与 mmcv-full（只装 mmcv-full）
  - 随便升级 numpy / opencv / pillow

1. 前置条件
--------------------------------------------------------------------------------

1.1 NVIDIA GPU + 驱动
  Windows / WSL2 下在 PowerShell 或容器内执行：
    nvidia-smi
  能看到 GPU 即可。驱动显示的 “CUDA Version” 可以高于 11.3。

1.2 Conda（Anaconda / Miniconda / Miniforge 任一）
  确认：
    conda --version

1.3 编译工具（编译本仓库 CUDA 扩展需要）
  Linux / 容器内建议有：
    g++, gcc, make, git
  Ubuntu 示例（有权限时）：
    apt-get update
    apt-get install -y build-essential git libgl1-mesa-glx libglib2.0-0

1.4 本机路径约定（本项目常用映射，可按你的机器改）
  Windows:  E:\WSL\wsl_projects  -> 容器: /workspace/project
  Windows:  E:\WSL\wsl_datasets  -> 容器: /workspace/datasets
  Windows:  E:\WSL\wsl_outputs   -> 容器: /workspace/outputs

  代码目录示例：
    /workspace/project/codes/bevfusion_mit_han_lab
  nuScenes mini 示例：
    /workspace/datasets/v1.0-mini
    （内含 maps/ samples/ sweeps/ v1.0-mini/）

13. 常见问题与处理
--------------------------------------------------------------------------------

[A] pip install mmcv-full==1.4.0 很慢 / 失败 / 开始本地编译
  原因：没走 OpenMMLab 预编译源，或 torch/cuda 版本不匹配。
  处理：确认 torch==1.10.1 且 cudatoolkit=11.3，然后用第 5 节带 -f 的命令。

[B] 同时装了 mmcv 和 mmcv-full 后 import 异常
  处理：
    pip uninstall -y mmcv mmcv-full
    再只装 mmcv-full（第 5 节）。

[C] mpi4py 报 mpi.h: No such file / Cannot compile MPI programs
  原因：系统没有 OpenMPI 开发包，或 apt 装失败。
  处理：用第 6 节 conda-forge 安装，不要强依赖 apt。

[D] from mpi4py import MPI 报 plm_rsh_agent / ssh : rsh
  处理：
    export OMPI_MCA_plm_rsh_agent=sh
    export OMPI_MCA_btl=tcp,self
  并确保 conda 装了 openssh。

[E] numba 报 SystemError: initialization of _internal failed
  原因：numba 过旧，与当前 numpy 不兼容。
  处理：pip install numba==0.58.1

[F] python setup.py develop 编译失败（找不到 CUDA / nvcc）
  处理：
    which nvcc
    export FORCE_CUDA=1
    export CUDA_HOME=你的CUDA路径
    确保安装了 CUDA devel 工具（仅 runtime 不够）。

[G] 训练 OOM（显存不足）
  处理：--data.samples_per_gpu 1
        可再降 workers：--data.workers_per_gpu 2
        先跑 LiDAR-only 配置。

[H] create_data / 训练找不到数据
  处理：确认 data/nuscenes 软链接指向包含
        maps samples sweeps v1.0-mini 的根目录。

16. 本机实际踩坑补充（WSL/Docker + CUDA 12.x + RTX 3060）
--------------------------------------------------------------------------------

1) data/nuscenes 必须是软链接，不要拷贝整份数据集：
     mkdir -p data
     ln -sfn /workspace/datasets/v1.0-mini data/nuscenes

2) 编译 CUDA 扩展时，若系统是 CUDA 12.x、PyTorch 是 cu113：
   - install_env.sh 已自动：绕过 torch CUDA 版本检查
   - install_env.sh 已自动：修补 Macros.h 的 uint32_t 问题
   - 仍可能出现个别样本 spconv 内核报错；推理演示请用:
       bash run_bevfusion.sh demo 10
   - 完整稳定评测更推荐官方 Docker（CUDA 11.3）

3) 仓库根目录若出现 ./nuscenes/*.pkl，是旧 converter 路径 bug 的残留，
   可直接删除；正确 pkl 应在 data/nuscenes/ 下。

4) 训练（单卡示例）:
     bash run_bevfusion.sh train-lidar
     EPOCHS=20 bash run_bevfusion.sh train-lidar
     bash run_bevfusion.sh train-fusion   # 需先下载融合相关预训练
